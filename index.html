// 01 — Features

Everything you need to monitor, capture, and prove.

هر چیزی که برای پایش، ثبت و اثبات نیاز داری.

Nine log types, professional HTML reporting, SHA-256 integrity, and automatic export triggered by an authorized USB drive.

۹ نوع لاگ، گزارش HTML حرفه‌ای، تأیید SHA-256 و خروجی خودکار با وصل کردن فلش مجاز.

Keyboard Logger

کی‌لاگر

Captures native (Persian/English) character, English equivalent from physical key, and Windows virtual key code — all in one line.

کاراکتر نهایی (فارسی/انگلیسی)، معادل انگلیسی کلید فیزیکی و کد VK ویندوز — همه در یک خط.

CHAR · EN · VK

Active Window Monitor

پایش پنجره فعال

Records process name and window title on every focus change. Know exactly which app was in front at every moment.

نام پروسه و عنوان پنجره در هر تغییر فوکوس. دقیقاً می‌دانی در هر لحظه کدام برنامه فعال بوده.

win32gui

Browser History

تاریخچه مرورگر

Extracts Chrome and Edge SQLite history every 5 minutes. Top sites, visit times, and page titles — automatically aggregated.

تاریخچه‌ی Chrome و Edge از SQLite هر ۵ دقیقه. سایت‌های پرکاربرد، زمان بازدید و عنوان صفحات — خودکار جمع‌آوری می‌شوند.

sqlite3

Clipboard Monitor

پایش کلیپ‌بورد

Captures every clipboard change with a 500-character preview. Passwords, tokens, URLs — nothing slips through.

ثبت هر تغییر کلیپ‌بورد با پیش‌نمایش ۵۰۰ کاراکتری. رمز، توکن، لینک — هیچ‌چیز از دست نمی‌رود.

win32clipboard

Process Monitor

پایش پروسه‌ها

Records every newly launched process with PID, username, and full executable path. Catches hidden background launches.

ثبت هر پروسه‌ی جدید با PID، نام کاربر و مسیر کامل فایل اجرایی. حتی پروسه‌های مخفی پس‌زمینه.

psutil

Auto-Export on USB

خروجی خودکار روی فلش

Detects authorized USB drives via marker file (ALEXANDRIA.md) and exports everything automatically — no manual interaction.

تشخیص فلش مجاز با فایل نشانه (ALEXANDRIA.md) و خروجی خودکار — بدون هیچ دخالت دستی.

v3 · Marker File

HTML Forensics Report

گزارش جرم‌شناسی HTML

GitHub-dark dashboard with statistics, bar charts, top apps, top sites — generated automatically at export time.

داشبورد دارک-مود با آمار، نمودار میله‌ای، پرکاربردترین برنامه‌ها و سایت‌ها — خودکار در زمان خروجی.

report.html

SHA-256 Integrity

یکپارچگی SHA-256

Every exported file gets a cryptographic hash in _hashes.sha256. Court-admissible proof that logs haven't been tampered with.

هر فایل خروجی یک هش رمزنگاری‌شده در _hashes.sha256 می‌گیرد. اثبات قابل ارائه در دادگاه که لاگ‌ها دستکاری نشده‌اند.

hashlib

ZIP Compressed Export

خروجی فشرده ZIP

All logs compressed into a single alexandria_export.zip. Text logs compress 3–5×, making evidence transfer fast.

همه‌ی لاگ‌ها در یک alexandria_export.zip. لاگ‌های متنی ۳ تا ۵ برابر فشرده می‌شوند — انتقال سریع شواهد.

// 02 — Auto-Export

Plug in. Get everything. No clicks needed.

وصل کن. همه‌چیز را بگیر. نیازی به کلیک نیست.

Alexandria polls removable drives every 5 seconds. When it finds a USB with the marker file, it exports everything automatically.

الکساندریا هر ۵ ثانیه درایوهای قابل جابجایی را چک می‌کند. وقتی فلشی با فایل نشانه پیدا کرد، خودکار همه‌چیز را خروجی می‌گیرد.

1

Mark USB

علامت‌گذاری فلش

Run mark_usb.bat once. It creates ALEXANDRIA.md with the authorized content.

یک بار mark_usb.bat را اجرا کن. فایل ALEXANDRIA.md با محتوای مجاز ساخته می‌شود.

2

Detect Marker

تشخیص نشانه

Alexandria polls drives every 5 seconds. Only marker files with exact content match are trusted.

الکساندریا هر ۵ ثانیه درایوها را چک می‌کند. فقط نشانه‌ی با محتوای دقیق قابل اعتماد است.

3

Auto-Export

خروجی خودکار

Logs copied. HTML report generated. SHA-256 manifest created. ZIP archive built.

لاگ‌ها کپی می‌شوند. گزارش HTML ساخته می‌شود. مانیفست SHA-256 تولید می‌شود. آرشیو ZIP ساخته می‌شود.

4

Done in Seconds

در چند ثانیه تمام

Total time: under 5 seconds. Event logged in usb_*.txt for audit trail.

زمان کل: کمتر از ۵ ثانیه. رویداد در usb_*.txt برای ردیابی ثبت می‌شود.

"auto_export_enabled": true, "auto_export_marker_file": "ALEXANDRIA.md", "auto_export_marker_content": "ALEXANDRIA-AUTHORIZED-EXPORT-KEY-v3-2026", "auto_export_check_interval": 5

// 04 — FAQ

Frequently asked questions.

سؤالات متداول.

Is Alexandria a keylogger?آیا الکساندریا یک کی‌لاگر است؟
Technically, yes — it captures keystrokes. But it's far more: it captures windows, processes, clipboard, browser history, USB events, and system info, then produces a professional report with integrity verification.
از نظر فنی بله — کیبورد را ثبت می‌کند. اما بسیار بیشتر از آن است: پنجره‌ها، پروسه‌ها، کلیپ‌بورد، تاریخچه مرورگر، رویدادهای USB و اطلاعات سیستم را هم ثبت می‌کند و یک گزارش حرفه‌ای با تأیید یکپارچگی تولید می‌کند.
Is this legal?آیا این قانونی است؟
Only with written authorization. Deploying this on any system without explicit permission is illegal in most jurisdictions. This tool is designed for authorized cybersecurity laboratory environments.
فقط با مجوز کتبی. استقرار این ابزار روی هر سیستمی بدون اجازه‌ی صریح در بیشتر کشورها غیرقانونی است. این ابزار برای محیط آزمایشگاهی امنیت سایبری مجاز طراحی شده.
How does auto-export know which USB to trust?خروجی خودکار چطور می‌فهمد به کدام فلش اعتماد کند؟
It checks for a file named ALEXANDRIA.md with specific content. The content is defined in config.json and can be changed by the user. Only USBs with a matching marker will trigger export.
فایل ALEXANDRIA.md را با محتوای مشخص در config.json چک می‌کند. فقط فلشی با نشانه‌ی مطابق می‌تواند export را تریگر کند.
Can someone fake the marker file?آیا کسی می‌تواند فایل نشانه را جعل کند؟
Yes — anyone who knows the marker content can create a fake USB. This is why the marker content should be kept secret and treated like a password. For higher security, consider adding encryption or a signed certificate.
بله — هر کسی که محتوای نشانه را بداند. به همین دلیل محتوای نشانه باید مخفی بماند. برای امنیت بالاتر، رمزنگاری یا امضای دیجیتال اضافه کن.
Will antivirus flag alexandria.exe?آیا آنتی‌ویروس alexandria.exe را تشخیص می‌دهد؟
Likely yes on first run — PyInstaller binaries often trigger heuristic detection. The install.bat script automatically adds a Windows Defender exclusion. For other AV products, add the exclusion manually.
احتمالاً بله در اولین اجرا. اسکریپت install.bat خودکار پوشه را در Windows Defender استثنا می‌کند.
Can I run this on Linux or macOS?آیا روی لینوکس یا مک اجرا می‌شود؟
No — it relies on Windows-specific APIs (win32gui, win32clipboard, Registry, Task Scheduler).
خیر — به APIهای مخصوص ویندوز وابسته است.
How do I verify the SHA-256 manifest?چطور مانیفست SHA-256 را بررسی کنم؟
On Windows PowerShell: Get-FileHash .\keylog_20261007.txt -Algorithm SHA256 — then compare with the entry in _hashes.sha256.
در PowerShell ویندوز: Get-FileHash .\keylog_20261007.txt -Algorithm SHA256 — و با مقدار در _hashes.sha256 مقایسه کن.
