----------------------------------------------------------------
  SECTION 2 - BUILD COMMANDS (Developer PC)
----------------------------------------------------------------

Install Python dependencies
    pip install pynput psutil pywin32 pyinstaller

Navigate to project folder
    cd CUserslenovoDesktopCyberProject

Build EXE from source (one-file, no console)
    pyinstaller --noconsole --onefile --name alexandria alexandria.py

Copy EXE to project root
    copy Y distalexandria.exe .

Run source directly (for testing)
    python alexandria.py

Run export mode from command line
    python alexandria.py --export E.

Kill all running instances before rebuild
    taskkill f im alexandria.exe

Clean build artifacts
    rmdir S Q build
    rmdir S Q dist
    del alexandria.spec


----------------------------------------------------------------
  SECTION 3 - INSTALLATION (Day 1 - On Target System)
----------------------------------------------------------------

Step 1 Insert USB flash drive into target system.

Step 2 In File Explorer, open the USB drive.

Step 3 Right-click install.bat - Run as administrator.

Step 4 When UAC prompts, click Yes.

Step 5 Wait for these messages
        [] Installing Alexandria...
        [] Adding Windows Defender exclusion...
        [] Creating Run Key...
        [] Creating Scheduled Task...
        [] Starting Alexandria...
        [OK] Alexandria installed and running.
        [OK] You can now remove the USB drive.

Step 6 Wait 5 seconds for the window to close.

Step 7 Safely remove the USB flash drive.

Step 8 Verify installation (see Section 4).


----------------------------------------------------------------
  SECTION 4 - VERIFICATION AFTER INSTALL
----------------------------------------------------------------

Check if Alexandria is running
    tasklist  findstr alexandria
    EXPECTED exactly ONE line

Check installed files
    dir %APPDATA%Alexandria
    EXPECTED alexandria.exe and logs folder

Check log folder contents
    dir %APPDATA%Alexandrialogs
    EXPECTED system_YYYYMMDD.txt (created immediately)

Check system info log
    type %APPDATA%Alexandrialogssystem_YYYYMMDD.txt
    EXPECTED one line of JSON with hostname, OS, CPU, RAM

Test keylogger (type a few words in Notepad first)
    type %APPDATA%Alexandrialogskeylog_YYYYMMDD.txt
    EXPECTED lines with CHAR  EN  VK

Check Run Key
    reg query HKCUSoftwareMicrosoftWindowsCurrentVersionRun v AlexandriaMonitor

Check Scheduled Task
    schtasks Query TN AlexandriaTask

----------------------------------------------------------------
  SECTION 10 - TROUBLESHOOTING
----------------------------------------------------------------

--- Access Denied on installuninstall ---
Cause CMD not running as administrator.
Fix   Right-click the .bat file - Run as administrator.

--- Antivirus quarantined alexandria.exe ---
Cause PyInstaller binaries are often flagged as heuristic malware.
Fix   Add exclusion manually
       Settings - Privacy & security - Windows Security
       - Virus & threat protection - Manage settings
       - Exclusions - Add an exclusion - Folder
       - %APPDATA%Alexandria

--- Alexandria not running after install ---
Diagnose
    tasklist  findstr alexandria
    dir %APPDATA%Alexandria
Fix Re-run install.bat as administrator.

--- Program does not start after reboot ---
Check Run Key
    reg query HKCUSoftwareMicrosoftWindowsCurrentVersionRun v AlexandriaMonitor
Check Scheduled Task
    schtasks Query TN AlexandriaTask
Re-run install.bat if either is missing.

--- Multiple identical log lines per keypress ---
Cause Multiple Alexandria instances running simultaneously.
Fix  
    taskkill f im alexandria.exe
    (then start one instance again)
The single-instance Mutex prevents this automatically in v2.

--- export.bat says Not a removable USB drive ---
Cause export.bat was run from C or desktop, not from the USB.
Fix   Copy export.bat to the USB root and run it from there.

--- report.html missing ---
Cause enable_html_report set to false in config.json.
Fix   Set to true in config.json, re-run export.

--- File locked, cannot delete Alexandria folder ---
Fix (as administrator)
    taskkill f im alexandria.exe
    rmdir S Q %APPDATA%Alexandria


----------------------------------------------------------------
  SECTION 11 - EMERGENCY CLEANUP (Administrator)
----------------------------------------------------------------

Open CMD as Administrator, then run in order

1. Stop scheduled task
    schtasks Delete TN AlexandriaTask F

2. Remove Run Key
    reg delete HKCUSoftwareMicrosoftWindowsCurrentVersionRun v AlexandriaMonitor f

3. Kill all running instances
    taskkill f im alexandria.exe

4. Remove Defender exclusion
    powershell -Command Remove-MpPreference -ExclusionPath '%APPDATA%Alexandria'

5. Remove files
    rmdir S Q %APPDATA%Alexandria

6. Verify
    tasklist  findstr alexandria
    dir %APPDATA%Alexandria

----------------------------------------------------------------
  SECTION 13 - PERSISTENCE MECHANISMS
----------------------------------------------------------------

Alexandria uses TWO persistence methods

1. Registry Run Key
   Location    HKCUSoftwareMicrosoftWindowsCurrentVersionRun
   Value name  AlexandriaMonitor
   Trigger     User logon

2. Scheduled Task
   Task name   AlexandriaTask
   Trigger     ONLOGON
   Run level   LIMITED (current user)

Protection
   Single-instance Windows Mutex
   Name     GlobalAlexandria_Lab_Monitor_Mutex_2026
   Purpose  Prevents multiple simultaneous instances
